# New Orleans Complete Streets Coalition
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Astro, static output, TypeScript, GitHub Pages, hosted Pages CMS. Coolify-compatible static output.

## Users
New Orleans residents seeking safer streets, potential members, event organizers, coalition partners, researchers and public officials.

## Product Purpose
Explain complete streets, make coalition participation straightforward, and make policies, dated evidence and project information easy to find.

## Brand Commitments
Preserve the supplied logo and blue/yellow/grey identity. Barlow Condensed headings and regular Barlow body, as agreed during planning. The user explicitly rejects generic AI-looking typography. Real New Orleans photographs, plain language, no invented claims.

## Operating Context
Meetings normally take place on the third Wednesday, 3–4:30 p.m., at Greater New Orleans Foundation, 919 St Charles Ave. The November 18, 2026 notes cancel December and identify January 20, 2027 as the next meeting.

## Capabilities and Constraints
Full wishlist; browser editing; public-facing summaries from all supplied sources. Bike Streets embedded for bike routes. ArcGIS StoryMap first for infrastructure projects, with external Better Streets link. Newsletter provider deferred. No raw private notes or contact lists published. No automatic event certification.

## Evidence on Hand
Original archive in Downloads: NOCSC Files-20261120T220929Z-1-001.zip. Brand standards, strategic plan, charter, logos, report card, policy memorandum, project inventory, and meeting notes. Public site nolacompletestreets.org; structural reference bigeasybudget.org. Current member roles and certification handouts need editorial confirmation.

## Accessibility & Inclusion
All travel modes represented. Target WCAG 2.2 AA, readable text, visible keyboard focus, reduced motion, semantic reading order, external links for embedded maps.
